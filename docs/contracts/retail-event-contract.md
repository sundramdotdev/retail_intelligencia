# docs/contracts/retail-event-contract.md — Common Retail Event Contract

> **THE FOUNDATIONAL EVENT ENVELOPE OF RETAIL INTELLIGENCIA**
> 
> This document defines the canonical JSON envelope for all intelligence generated by edge nodes across the platform. Every edge observation must conform strictly to this specification.

---

## 1. Canonical Event JSON Specification

Every edge node, backend validator, persistence worker, and realtime consumer must strictly adhere to this exact JSON schema:

```json
{
  "eventId": "evt_01J98X7Z8K3M0W4V8R9N1P2Q3R",
  "eventVersion": "1.0",
  "eventType": "SHELF_LOW_STOCK",
  "deviceId": "edge_001",
  "storeId": "store_001",
  "zoneId": "zone_aisle_04",
  "timestamp": "2026-09-05T10:30:00Z",
  "confidence": 0.94,
  "severity": "HIGH",
  "metadata": {
    "shelfId": "shelf_04_b",
    "productCategory": "Beverages",
    "occupancyPercentage": 15.0,
    "threshold": 25.0
  },
  "source": {
    "cameraId": "cam_04",
    "modelId": "shelf-detector-yolov8",
    "modelVersion": "1.0.0"
  },
  "schemaVersion": "1.0"
}
```

## 2. Field Definitions and Constraints

| Field Name | Type | Required | Format / Regex / Enum | Description |
| :--- | :---: | :---: | :--- | :--- |
| `eventId` | `string` | **YES** | `^evt_[0-9A-HJKMNP-TV-Z]{26}$` (ULID) | Globally unique identifier generated on edge. Guaranteed monotonic and collision-free. |
| `eventVersion` | `string` | **YES** | SemVer (e.g., `"1.0"`) | Version of the specific event type definition. |
| `eventType` | `string` | **YES** | Enum (See [docs/contracts/event-types.md](file:///c:/hackathon/retail_intelligencia/docs/contracts/event-types.md)) | Identifies the physical retail condition detected. |
| `deviceId` | `string` | **YES** | `^[a-z0-9_-]{3,32}$` | Unique identifier of the physical edge appliance that processed the stream. |
| `storeId` | `string` | **YES** | `^[a-z0-9_-]{3,32}$` | Unique identifier of the retail store location. |
| `zoneId` | `string` | **YES** | `^[a-z0-9_-]{3,64}$` | Unique identifier of the calibrated spatial floor zone where the event occurred. |
| `timestamp` | `string` | **YES** | ISO-8601 UTC (`YYYY-MM-DDTHH:mm:ssZ`) | The exact UTC instant at which the retail condition was synthesized on the edge. |
| `confidence` | `number` | **YES** | Float between `0.00` and `1.00` | Model detection or statistical confidence score. |
| `severity` | `string` | **YES** | `"INFO"`, `"LOW"`, `"MEDIUM"`, `"HIGH"`, `"CRITICAL"` | Operational urgency classification. |
| `metadata` | `object` | **YES** | Key-value JSON Object | Event-specific data payload conforming to the event type schema. |
| `source` | `object` | **YES** | Structured provenance object | Identifies hardware and model lineage for auditability. |
| `source.cameraId` | `string` | **YES** | `^[a-z0-9_-]{3,32}$` | Identifier of the physical camera sensor capturing the scene. |
| `source.modelId` | `string` | **YES** | String | Identifier of the AI vision model architecture used. |
| `source.modelVersion` | `string` | **YES** | SemVer (e.g., `"1.2.0"`) | Version of the model weights / engine deployed. |
| `schemaVersion` | `string` | **YES** | Fixed string: `"1.0"` | Version of this envelope contract. |

---

## 3. Mandatory Governance Rules

1. **Strict Immutability**: Once an event envelope is synthesized by the edge rule engine, no field may be altered in transit.
2. **Universal Envelope**: No team or microservice may invent an alternative event wrapper. All retail intelligence must travel inside this canonical structure.
3. **UTC Timezone Invariant**: Timestamps must strictly be UTC strings terminated with `Z`. Local store time zone offsets are calculated exclusively in the presentation/data layer.
4. **Idempotent Consumers**: Backend services must treat `eventId` as an absolute deduplication key. Repeated deliveries of the same `eventId` must be acknowledged and ignored.
5. **No Biometric Data in Metadata**: The `metadata` payload must never contain facial landmarks, customer demographic estimates, or cross-camera customer identifiers.
